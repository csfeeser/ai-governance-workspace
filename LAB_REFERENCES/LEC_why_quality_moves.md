# Why Quality Moves

When an AI workflow's quality score drops, it moved for a reason and the reason is findable. This lecture gives the four causes of degradation (changed inputs, a vendor model update, a changed company policy, a modified prompt) and the specific place each one leaves evidence. It also defines what a documented test must contain so a third party can act on it, which students produce in Lab 2.2.

**Resources**
- [Microsoft Purview audit solutions](https://learn.microsoft.com/purview/audit-solutions-overview): the real documentation behind the activity-log method this lecture teaches. It is where the model-identity columns this lecture flags as the fingerprint of a vendor model change actually come from on a Microsoft Copilot tenant.
- [Anthropic for Enterprise](https://www.anthropic.com/enterprise): the equivalent starting point on the Claude side, so the "check the activity log for a model change" habit isn't tied to one vendor.
